# Local Agent Workspace

A local, single-user browser coding assistant powered by Databricks model
serving: streamed chat, local file and shell tools, per-conversation
permissions, context compaction with handoff files, usage tracking, MCP
servers, skills and hooks. It runs with Python only; the frontend has no
build step.

See [`local-agent-workspace/README.md`](local-agent-workspace/README.md) for
setup, usage and development.
